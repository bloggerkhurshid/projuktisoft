## 🚀 About ProjuktiSoft

**ProjuktiSoft** is an independent software development studio run by a full-stack MERN developer based in Kokrajhar, Assam, India. We design and engineer production-ready web applications, regional EdTech platforms like **DailyAxom** (serving 5,000+ competitive exam learners across Assam), POS business software, and custom full-stack solutions.

---

## ✨ Features

- 🎨 **Modern Light Glassmorphism UI**: Built with a clean background grid pattern, `#37B37F` electric emerald accent color, smooth backdrop-blur glass panels, and confident typography.
- ⚡ **Next.js 16 App Router + Turbopack**: Blazing-fast page load performance, static optimization, and modular TypeScript components.
- 🎓 **Flagship Product Showcase**: Spotlight showcase for **DailyAxom**, featuring bilingual practice test engines (Assamese & English) and real-time student analytics.
- 💼 **Careers & Internship Portal (`/careers`)**: Dedicated hiring hub for *Content Writer Interns (DailyAxom)* and *Junior Developer Interns (ProjuktiSoft Studio)* featuring verified Certificate with Training credentials and mandatory portfolio submission.
- 💬 **Backendless Form Briefs & WhatsApp Integration**: Direct inquiry brief submission routing via FormSubmit AJAX to `contact@projuktisoft.com` and pre-filled WhatsApp communication links (`+91 7002820458`).
- 📱 **100% Fully Responsive Layout**: Mobile-first responsive navigation drawer, strategy call booking modal, and interactive service scope modals.

## 💻 Local Development Setup

### Prerequisites
- Node.js 18.x or later installed
- npm / yarn / pnpm package manager

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/bloggerkhurshid/projuktisoft.git
   cd projuktisoft
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Verify Production Build**:
   ```bash
   npm run build
   ```
